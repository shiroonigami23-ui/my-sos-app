# 🗺 Roadmap — My SOS — Offline Emergency Mesh

> Back to the [README](../README.md).

## Where the project stands

Status: **phase 2**.

## Milestones

### Phase 2 — Toolkit (done)

- [x] ESP-NOW mesh with GPS JSON alerts and relay
- [x] PWA control panel
- [x] Android app with native C engine + release workflow

### Phase 2.5 — Wearable wristband

*Goal:* Turn a node into a wrist-worn SOS device.

- [ ] Miniature ESP32 + GPS + LiPo stack
- [ ] Underside capacitive distress pad with long-press
- [ ] Haptic confirmations
- [ ] Printed enclosure and silicone strap

### Phase 3 — Range & reliability

*Goal:* Reach farther and never lose a message.

- [ ] LoRa (SX1276) radio option for kilometre-scale range
- [ ] Message de-duplication + TTL in the relay logic
- [ ] Delivery acknowledgements and retry queue on the nodes

### Phase 4 — Usability

- [ ] Styled PWA with map view of incoming SOS locations
- [ ] Bluetooth link between Android app and nearest node
- [ ] Battery-powered enclosure design (3D-printable)

## 🔭 Long-term Vision

A pocket-sized, community-deployable safety net for trekkers, rural areas and disaster zones where phones go silent.

## How to help

Pick any unchecked item, open an issue to discuss the approach, then send a PR. Items in the earliest unfinished milestone are the highest priority.
